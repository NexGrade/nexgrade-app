## 2. Banco de teste local (novo)
- PostgreSQL 17 nesta máquina (serviço `postgresql-x64-17`), com o banco **`nexgrade_teste`**, só para teste. A senha do usuário `postgres` fica em `%APPDATA%\postgresql\pgpass.conf`, e por isso a URL vai sem senha:
  - migrações: `DATABASE_URL=postgresql://postgres@localhost:5432/nexgrade_teste pnpm --filter @workspace/db run migrate`
  - testes de integração: `TEST_DATABASE_URL=postgresql://postgres@localhost:5432/nexgrade_teste pnpm --filter @workspace/api-server run test` (01/11: **194/194**, nenhum pulado)
- **Cuidado:** sem `DATABASE_URL` no ambiente, o `drizzle-kit` lê `lib/db/.env`, que aponta para o **banco real** (Supabase). Para mexer no banco local, a variável vai sempre no próprio comando.
